# docs

このアプリの設計メモ・改善案の置き場です。実装済みの内容は `README.md`（リポジトリ直下）に、これから検討・実装するものはここに置きます。

| ファイル | 内容 |
|---|---|
| [backlog.md](backlog.md) | 改善バックログ。レビューで洗い出した課題と追加機能案を優先度つきで管理 |
| [cloudkit.md](cloudkit.md) | iPhone / iPad 間の同期に向けた CloudKit 導入の検討メモ |

## 運用ルール

- 新しく思いついた機能案は `backlog.md` の「追加機能案」に1行足す。詳細な設計が必要になった段階で個別のファイルに切り出す。
- 着手したら `[ ]` を `[x]` にし、リリースに含めたら README 側の記述を更新する。
